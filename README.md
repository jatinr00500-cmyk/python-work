# python-basics-25BCOM2853
# Session 4 Python Programs

## WHAT
This repository contains six fundamental Python programs:

armstrong.py: Checks if a given number is an Armstrong number.
factorial.py: Calculates the factorial of a number n.
fibonacci.py: Generates the Fibonacci sequence.
prime.py: Checks if a number is prime.
pronic.py: Evaluates if a number is a pronic number.
struct.py: Stores student data using a dictionary.

## RUN
You can execute each script directly from your terminal using Python:
*   `python armstrong.py`
*   `python factorial.py`
*   `python fibonacci.py`
*   `python prime.py`
*   `python pronic.py`
*   `python struct.py`
Execute via terminal: python <filename.py>

## NEEDS
*   Requires Python 3.x installed on your system.
*   No external dependencies or installations are required (uses standard library only).
